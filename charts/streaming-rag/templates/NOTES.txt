Streaming RAG has been installed as release {{ .Release.Name }} in namespace {{ .Release.Namespace }}.

1. Wait for the Ollama model pull (Job ollama-init) and pods to become Ready:
   kubectl get pods,jobs -n {{ .Release.Namespace }} -w

2. Port-forward the API and MCP services:
   kubectl port-forward -n {{ .Release.Namespace }} svc/api 8000:8000
   kubectl port-forward -n {{ .Release.Namespace }} svc/mcp {{ .Values.mcp.port }}:{{ .Values.mcp.port }}

3. Health check:
   curl http://localhost:8000/health

4. Query:
   curl -s -X POST http://localhost:8000/api/v1/query \
     -H "Content-Type: application/json" \
     -d '{"prompt": "what errors occurred recently?", "k": 5}'

MCP SSE (Cursor): http://localhost:{{ .Values.mcp.port }}/sse
